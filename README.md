# AI+ 虚拟仿真材料实验平台 · 前端重制

这是原项目的本地前端重制版，基于 [AI-Materials](https://github.com/xiaohetaoo/AI-Materials) 的 `ae2fe1f`。双击 `index.html`，用 Edge、Chrome 或 Firefox 打开即可使用。不需要安装依赖，也不需要构建。

1. 在首页选择实验，或点击「进入实验台」继续最近使用的模块。
2. 选择材料体系，加载工艺预设或自行调参，再点击「运行仿真」。手机上先点「展开参数」即可修改条件。
3. 在「仿真与曲线」查看过程与指标，在「参数影响」查看单个参数的影响。
4. 在「数据与报告」勾选 2–5 组记录后点击「开始对比」，也可导出 CSV 或生成实验报告。
5. 在顶栏打开实验指导、术语库或 AI 助手。工艺寻优、敏感性分析和本地诊断无需配置外部模型。

包含六个仿真实验、58 个材料体系和 98 条术语。碳钢热处理模块可比较 20 钢、45 钢和 T8 钢的淬火、回火及 CCT 冷却路径。保留更新历史、实时演算、报告和深色模式。外部 AI 对话仍是可选功能，需要自行配置服务商接口。

实验记录、主题与 AI 配置存在浏览器中。备份包包含完整网页源码与资源；要备份自己的实验记录，请另行导出 CSV。
